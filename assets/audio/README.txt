# Assets
#
# The game reads these at runtime and stays silent when a file is absent, so
# an empty folder is a valid state.
#
# Drop files here with these exact names to bring the audio to life:
#
#   swap.mp3       tile drag and swap
#   invalid.mp3    a swap that formed nothing
#   match.mp3      an ordinary clear
#   special.mp3    a special candy created or a hammer hit
#   rocket.mp3     a striped candy detonating
#   bomb.mp3       a wrapped candy detonating
#   rainbow.mp3    a colour bomb detonating
#   cascade.mp3    a chain reaction step
#   star.mp3       a jelly token collected, or a star awarded
#   win.mp3        level cleared
#   lose.mp3       out of moves
#   click.mp3      a menu press
#   music.mp3      looping background music
#
# Keep every effect short, under a second, and normalise them to about the same
# loudness. Music should be a seamless loop, ideally 60 to 90 seconds.
